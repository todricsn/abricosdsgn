# Reference assets

Source page: https://npopis.ru/tekhnologicheskiye-resheniya/

This folder contains the page's localized stylesheets, backgrounds, architecture photographs, workflow icons, and thumbnail galleries. `manifest.json` maps original URLs to local paths and records file hashes. Original stylesheet headers are retained. No original JavaScript, analytics or form endpoints are included.

Projects, document thumbnails and third-party logos are explicitly identified on the page as reference examples. They do not describe Abricos's completed work or credentials. Full-size reference documents are linked to their source rather than packaged.
