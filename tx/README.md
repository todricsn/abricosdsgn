# Абрикос — технологические решения

Самостоятельный статический сайт внутри `tx/`. Адрес GitHub Pages — `/tx/`.

Текущая версия повторяет структуру, стили и изображения страницы https://npopis.ru/tekhnologicheskiye-resheniya/ по запросу на демонстрационный макет. Логотип, телефон и почта принадлежат Abricos. Вводный блок и этапы перенесены с предоставленных пользователем скриншотов; большое описание услуги написано самостоятельно. Проекты, документы и клиентские логотипы взяты из референса для последующей замены. Заголовки разделов и подписи проектов упрощены по запросу заказчика.

Содержимое редактируется в `index.html`, фирменные настройки и адаптация — в `tx.css`, интерактивные элементы — в `replica.js`. Исходные стили и изображения референса находятся в `reference/`, соответствие файлов исходным адресам — в `reference/manifest.json`.

Форма открывает почтовое приложение с подготовленным письмом на `abricos-design@mail.ru`. Серверной отправки и хранения заявок нет. На сервер конкурента данные не передаются.

Проверка логики: `node --test tx/tests/replica.test.cjs` из корня репозитория. Для локального просмотра: `python3 -m http.server 4174 --bind 127.0.0.1`, затем http://127.0.0.1:4174/tx/.

По последнему запросу убраны синий баннер с хлебными крошками, выпадающее меню и блок иконок в шапке, ссылки и эффект «Подробнее» на проектах. Шапка содержит только якоря текущей страницы. Логотип в подвале отображается без плашки, в светлом варианте через CSS; исходное прозрачное изображение сохранено.

Подвал сокращён до логотипа, копирайта, специализации, города и контактов. Меню в подвале и примечание под ним удалены.
