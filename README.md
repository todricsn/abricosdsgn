# Abricos Design

Статический сайт-визитка студии проектирования и дизайна коммерческих пространств.

## Структура

- `index.html` — главная страница;
- `portfolio/index.html` — портфолио;
- `styles.css` — все стили;
- `script.js` — меню, анимации, FAQ, фильтры и форма;
- `projects.json` — данные 11 работ;
- `images/` и `portfolio/` — изображения.

Фреймворки, сборщики и внешние библиотеки не используются.

## Локальный запуск

```bash
python3 -m http.server 4173
```

После запуска сайт доступен по адресу `http://localhost:4173/`.
