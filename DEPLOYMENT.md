# Публикация abricos-proekt.ru

После push в `main` workflow `Publish abricos-proekt.ru` проверяет сайт и загружает публичные файлы из `tx/` через FTPS. Можно запустить вручную: GitHub → Actions → Publish abricos-proekt.ru → Run workflow.

Один раз добавить в Settings → Secrets and variables → Actions → Repository secrets:

- `FTP_HOST` — имя FTP-сервера из панели хостинга, с действительным TLS-сертификатом.
- `FTP_USER` — существующий FTP-пользователь хостинга.
- `FTP_PASSWORD` — его пароль.
- `FTP_REMOTE_DIR` — существующий FTP-путь к корню сайта abricos-proekt.ru. В файловом менеджере это `/home/abr8054623/abricos-proekt.ru/docs`; FTP может показывать путь относительно домашнего каталога пользователя, поэтому его нужно проверить при подключении.

Пароли не добавлять в файлы репозитория. Нужен сервер с явным FTPS на порту 21; передача по незащищённому FTP не используется.

Служебные файлы, тесты, конфигурация и `.htaccess` не публикуются. Имеющиеся файлы сервера не удаляются. Каждый файл сначала загружается под временным именем, затем переименовывается; изображения и стили загружаются перед HTML.

Первый успешный запуск требует проверки FTP-доступа и пути на действующем хостинге. Если хостинг поддерживает только SFTP, этот загрузчик нужно заменить на SFTP перед использованием.
